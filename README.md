# ⏰ Persian Reminder | یادآور فارسی آبسیدین

**یک افزونه فارسی برای مدیریت وظایف و یادآوری‌ها در Obsidian، با پشتیبانی از تقویم شمسی، انتخاب ساعت، هشتگ‌ها و مکان‌ها.**

Persian Reminder با هدف فراهم‌کردن تجربه‌ای ساده، زیبا و کاملاً فارسی برای مدیریت یادآوری‌ها در محیط Obsidian طراحی شده است.

این افزونه به شما کمک می‌کند وظایف و کارهای روزانه خود را در یادداشت‌ها مدیریت کنید و برای آن‌ها تاریخ و ساعت یادآوری تعیین کنید.

## ✨ امکانات افزونه

### 📅 پشتیبانی از تقویم شمسی
- انتخاب تاریخ با تقویم جلالی
- نمایش تاریخ‌ها به زبان فارسی
- یکپارچگی با افزونه Persian Calendar
- پشتیبانی از اعداد فارسی

### 🕒 انتخاب ساعت
- ساعت عقربه‌ای با طراحی Material
- امکان انتخاب ساعت و دقیقه
- رابط کاربری ساده و مناسب صفحات لمسی

### 🔔 مدیریت یادآوری‌ها
- افزودن یادآوری به وظایف
- ویرایش تاریخ و ساعت یادآوری
- نمایش وظایف دارای یادآوری
- مشخص‌کردن وظایف نزدیک و عقب‌افتاده

### 🏷️ هشتگ‌ها و مکان‌ها
- افزودن هشتگ به وظایف
- دسته‌بندی و مدیریت بهتر یادآوری‌ها
- تعیین مکان برای یادآوری
- استفاده از رنگ‌های اختصاصی برای هشتگ‌ها

### 🎨 شخصی‌سازی ظاهر
- امکان انتخاب رنگ اصلی افزونه
- پشتیبانی از گرادیانت‌های رنگی
- طراحی کارت‌های وظایف
- سازگاری با حالت روشن و تاریک Obsidian

### 📋 پنل مدیریت وظایف
- نمایش یادآوری‌ها در نوار کناری
- داشبورد مدیریت وظایف
- نمایش وضعیت و زمان باقی‌مانده وظایف
- امکان مشاهده و مدیریت یادآوری‌ها

### 📱 سازگاری با موبایل
- رابط کاربری واکنش‌گرا
- پشتیبانی از نمایش راست‌به‌چپ (RTL)
- پنجره انتخاب یادآوری با سه تب مستقل:
  - 📅 تاریخ
  - 🕒 ساعت
  - 🏷️ جزئیات

## 📦 نصب افزونه

### نصب دستی

۱. آخرین نسخه افزونه را از بخش Releases مخزن دریافت کنید.

۲. سه فایل زیر را دانلود کنید:

```text
main.js
manifest.json
styles.css
```

۳. پوشه‌ای با نام `persian-reminder` در مسیر زیر ایجاد کنید:

```text
YourVault/.obsidian/plugins/persian-reminder/
```

۴. فایل‌های دانلودشده را داخل این پوشه قرار دهید.

۵. Obsidian را باز کنید.

۶. از بخش **Settings → Community plugins** افزونه Persian Reminder را فعال کنید.

## 📆 پیش‌نیاز

برای استفاده از امکانات تقویم شمسی، نصب و فعال‌بودن افزونه **Persian Calendar** ضروری است.

این افزونه از API تقویم فارسی برای تبدیل و مدیریت تاریخ‌ها استفاده می‌کند.

## 🚀 نحوه استفاده

۱. یک وظیفه در یادداشت خود ایجاد کنید.

۲. از امکانات Persian Reminder برای تعیین یادآوری استفاده کنید.

۳. تاریخ موردنظر را از تقویم شمسی انتخاب کنید.

۴. در تب ساعت، زمان یادآوری را مشخص کنید.

۵. در صورت نیاز، در تب جزئیات هشتگ یا مکان اضافه کنید.

۶. یادآوری را ذخیره کنید.

اکنون می‌توانید وظایف خود را از طریق پنل افزونه مدیریت کنید.

## 🛠️ توسعه افزونه

کد منبع افزونه به‌صورت ماژولار سازمان‌دهی شده است تا توسعه و نگهداری آن ساده‌تر باشد.

بخش‌های اصلی پروژه شامل موارد زیر هستند:

```text
src/
├── core/
├── editor/
├── shared/
├── ui/
├── views/
├── styles/
├── main.js
└── settings.js
```

برای ساخت نسخه قابل نصب، در پوشه پروژه دستور زیر را اجرا کنید:

```bash
npm run build
```

برای اجرای آزمون‌های داخلی:

```bash
npm test
```
